# SOC 2 Evidence: CC6.1 — Logical Access Controls

**Criterion:** CC6.1
**Responsible:** security-engineer
**Frequency:** quarterly

## Control Description

The entity implements logical access controls to protect its assets from unauthorized access.

## Test Procedure

1. Review access control policy
2. Sample user accounts and verify least privilege
3. Verify access review cadence
4. Check offboarding automation

## Expected Result

All user accounts have documented roles, least privilege is enforced, quarterly access reviews are completed, offboarding is automated within 24 hours.

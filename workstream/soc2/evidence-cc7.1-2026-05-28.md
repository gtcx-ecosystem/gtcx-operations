# SOC 2 Evidence — CC7.1: Security Operations

**Date:** 2026-05-28  
**Criterion:** CC7.1  
**Status:** Draft

---

## Control Description

The entity uses detection and monitoring procedures to identify security events and anomalies that could indicate security threats.

---

## Test Procedure

1. Review the security operations policy and incident response plan.
2. Verify that security monitoring tools (SIEM, IDS/IPS, EDR) are deployed and configured.
3. Inspect alerting rules and escalation procedures.
4. Sample security event logs and verify they are reviewed and acted upon.

---

## Expected Result

Security operations policy is current. Monitoring and detection tools are active with documented alerting thresholds. Security events are reviewed and escalated per the incident response plan.

- Security Operations Policy (ops/security-operations-policy.md)
- SIEM / monitoring dashboard screenshots or configurations
- Incident response tickets and post-mortem reports

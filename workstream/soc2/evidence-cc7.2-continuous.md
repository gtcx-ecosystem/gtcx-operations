# SOC 2 Evidence: CC7.2 — System Monitoring

**Criterion:** CC7.2
**Responsible:** platform-engineer

## Control Description

## Test Procedure

1. Verify monitoring dashboards exist
2. Check alerting thresholds
3. Validate health check automation

## Expected Result

All production services have monitoring dashboards. Alerts configured for p99 > 50ms, error rate > 0.1%.
